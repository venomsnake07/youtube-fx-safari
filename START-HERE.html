Build a signed YouTube FX Mac app so the extension stays installed when you quit Safari. Use linked sample-rate playback, independent pitch, and reverb with precise +/− controls.

This is a source package with a Mac installer. It builds and signs the app on your Mac using your own Apple Development certificate. It is not a pre-signed app download. A development signature can eventually need renewal.

1. Set up Apple signing once

  1. Install Xcode from Apple, open it once, and finish its setup.
  2. In Xcode → Settings → Accounts (or Apple Accounts), sign in with your Apple Account and select your team / Personal Team.
  3. Choose Manage Certificates… → + → Apple Development.

2. Build and install

  1. Extract the whole ZIP. Keep all its files together.
  2. In Finder, double-click INSTALL-ON-MAC.command. It checks the files, builds the app, signs and verifies it, then opens the installed copy in Home → Applications.
  3. After a successful build, remove the old Temporary YouTube FX entry in Safari → Settings → Extensions. Enable the installed entry and allow youtube.com and, if needed, music.youtube.com.
  4. Reload every YouTube tab. Set your sliders again if they reset.
  5. Quit Safari with ⌘Q and reopen it. Confirm the extension works with Allow unsigned extensions turned off.

Keep YouTube FX.app installed. You can close the app and Xcode after setup. Do not add this package through Add Temporary Extension for this installation.

If macOS blocks the command file

See PERMANENT-INSTALL.md for opening instructions, certificate setup, build errors, and signing limits. The installer leaves an existing app untouched if the new build or verification fails.

Your settings

The panel says v1.5.0. The signed copy has separate local settings from the temporary copy. Use Sample rate 95% with speed and pitch linked for a natural slowdown. Click Unlink to change speed and pitch separately. Every slider now has + / − buttons. Old saved pitch settings open in independent mode at their original speed.

Distribution and renewal

This personal development installation removes Safari’s temporary 24-hour limit and survives browser restarts. Apple certificates and trust can expire or be revoked; rebuild with a valid certificate if needed. A public App Store release or a Developer ID–signed and notarized download requires Apple Developer Program distribution steps.

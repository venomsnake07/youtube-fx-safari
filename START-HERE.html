Install without Xcode

  1. In Safari → Settings → Advanced, enable Show features for web developers.
  2. Go to the Developer tab and click Add Temporary Extension…. Approve the unsigned-extension prompt.
  3. Select the downloaded YouTube-FX-Safari-1.4.0.zip, or select the extracted folder containing manifest.json.
  4. In Settings → Extensions, enable YouTube FX and allow it on youtube.com. Also allow music.youtube.com if you use YouTube Music.
  5. Reload YouTube. Play a video, click the ƒx button at the bottom right, then click Enable effects.

Safari removes temporary extensions after 24 hours or when you quit Safari. Add the ZIP again to reload it. No Xcode or paid developer account is needed for this method. This is an unsigned development extension.

Updating from an earlier build

Remove the old temporary extension, add this ZIP, and reload every YouTube tab. Check the panel says v1.4.0. Use Normal (1×) playback speed and leave a video playing for 5–10 seconds. If Safari supplies silent samples, the extension will try its new buffered-audio route; look for Audio detected · Safari stream recovery.

Fewer interruptions in 1.4.0

The extension now retains buffered audio through brief player interruptions, avoids restarting for repeated stream headers or clock catch-up, and keeps a larger playback reserve. The stereo pitch engine is retained, with a clearer bass balance in long reverb tails. If a problem remains, diagnostics now record the reason for recent recovery transitions.

Your controls

Pitch changes the musical key. Reverb adds space. Open Fine tuning for cents, tail length, and volume. Click Effects on · Turn off for original audio; Reset also resets the pitch and reverb.

If the toolbar asks you to enable audio, click Enable audio in the panel on the YouTube page once. Safari may require that page click before processing.

If audio still does not change

With a video playing, open Troubleshooting → Copy diagnostics and review the report for private details before sharing it in a GitHub issue. This version includes stream format and decoder details. Recovery requires clear audio fragments visible to the page and may not support every YouTube stream.

If the button is missing

Allow the extension on youtube.com, reload the page, and open a video. Disable other volume or audio effect extensions if they compete for the same player. After removing or reloading this extension, reload YouTube as well.

The buffered-audio route compensates for the pitch processor’s delay. Direct audio processing adds some delay, and large shifts can still have audible artifacts. Protected rentals and remote playback paths such as AirPlay may not work. See README.md for the full guide and VALIDATION.md for test coverage.
